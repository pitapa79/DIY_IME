DIY_IME2 Windows x64 試用版

ZIPを展開し、DIY_IME2.exeを開いてください。ブラウザーで画面が開きます。
Git、Cargo、npmの導入やノードの再ビルドは不要です。
初回は同梱ノードの準備を待ってください。異なる版がある場合は現在の版を保持します。
「接続」してグラフを準備し、必要な実行・入力経路・辞書等の許可を確認して実行します。
同梱のサンプル辞書は「kousui」等の入力確認用です。一般文章の変換精度を保証しません。
終了は画面の「アプリを終了」を使います。処理の停止を待ってから終了を表示します。
画面との接続が失われた場合も、処理の停止を待って終了します。

データと許可・秘密の保管先は現在のユーザーのLocalAppData内DIY_IME2です。
既存の辞書は上書きしません。グラフはブラウザーの保持とJSON保存を利用します。
通信先のHost設定はデータフォルダー内settings.jsonのnetwork項目です。
秘密の値は画面から登録し、設定ファイルへは秘密の識別名を指定します。

本品はノードエディターとWasm実行の試用版です。WindowsのIME登録、TSF、ホットキー、
Nativeノードの隔離解除、公開署名には対応していません。
依存コンポーネントの原文表記はnoticesとofficial/noticesを参照してください。
