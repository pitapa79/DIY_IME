## 2. 試作から移せる知見と移せない保証

| 試作で確認したこと | 本番に不足する検証・契約 |
|---|---|
| 期限ちょうどの完了より期限を優先すると固定traceを再生できる | 到着の線形化点、単調時計、実スレッド・輸送の順序逆転とOS起床遅延 |
| 結果の配送権限と物理仕事の回収を別に扱う | ホストの真正な終了通知、故障/EOF/kill後の所有権と解放確認 |
| 取消を要求しただけで枠を返さない | 取消非協調・panic・無限待機の隔離と負荷時の入場制御 |
| session/plan/run/input/jobで旧結果を拒否できる | 永続・再接続を含むsessionEpoch、整数の安全な輸送、入力本文との対応 |
| 採用方針をSelectionPolicyとして交換できる | グラフ内の制御境界、共有仕事の参照、Pendingと通常入力の分離 |
| FIFO・容量・期限・履歴を有界にできる | 件数/byte数/保持期間の実測、設定幅、busyの契約、背圧と結果再取得 |

試作は実時計・スレッド・I/O・外部APIを使わず、静的小文字列、真正な手動完了、正しい方針を仮定する。有限run予算は試作の仮定であって製品の必須制限ではない。無期限待機と資源予約上限は別に検討する。同期Rust関数を安全に強制停止できるとは扱わない。
旧結果でも真正な完了なら旧仕事の資源回収に使える。sessionを切り替えたからといって所有仕事の記録まで消さない。副作用を行ったメール/書込/API操作は取消・rollbackで元に戻らず、結果不明の開始を自動再送しない。

### P1: 同期Nodeを維持してCoreへ完了・時計・協調取消の境界を接続する

目的: 重い仕事の完了前にも制御ループが次の完了・時計・取消を受け取れるようにする。
開始条件: P0のA/Tと正式fixtureがmainへ反映済み、開始SHAに#46を含む。
範囲: 表3のCore所有パス。通常Nodeは全入力解決後に一回実行を維持。明示した重いアダプターだけを有界な実行枠へ出す。通常の長いexecuteを制御ループ上で待たない。borrowしたRunContextを無断で別スレッドへ延命せず、入力/設定/計画・準備資源の所有スナップショットと解放時点を確定する。
契約: 完了と時計を線形化し、配送時・採用時に世代/期限を再検査。Nodeの方針がwait/select/cancel等を決め、Coreは妥当性・配送権限・共有参照を検査する。Coreに「速い候補が勝つ」や原文復帰の意味を追加しない。入力が来なくても登録した時刻に観測機会を作る。state取得だけで採用を進めない。
受け入れ検査: 正常完了、全入力待機の互換性、期限前/同時/後、明示取消、非協調な仕事の枠保持、旧run/plan/input/session/jobの拒否、真正な旧完了の回収、重複完了、共有仕事、満杯時busy、キュー/byte上限、panic、時計飛び越し。仮想時計の決定的検査と、停止ゲートで制御した実workerの負荷・寿命検査を分ける。
限界: in-processの強制停止と副作用の巻き戻しを保証しない。隔離ホストは別タスク。無制限スレッド作成や取消だけの早期枠返却は禁止。

### P2: 常駐CLI/ブリッジで受理・完了・取消・状態取得を分離する

目的: 長いrunの後ろにstatus/cancelが詰まる現在のv2の制約を、新方式だけで解消する。
開始条件: P0のB採用。P1統合SHAと型/fixture固定後に実接続する。
範囲: 表3の通信パス。UI本体とCore実行意味は変更しない。
契約案: startRun/getRun/cancelRunのpollingを初期比較候補とし、push案との遅延/背圧/再取得の違いをP0で決める。命名・版はまだ仮称。受理を成功と表示しない。包絡id/runId/planVersion/inputRevision/state.revisionを混用しない。u64をJSへ安全に渡す表現とsessionEpochを採用時に決める。旧v2には旧宣言・同期runを返す。
接続監視は処理期限と分離し、仕事が長いだけで健全な制御接続を切らない。#45の既定値/有限/無期限設定は旧経路の互換動作として維持。EOF・不正フレーム・プロセス停止は結果不明とし、startを自動再送しない。応答消失時の照会/重複排除、結果保持切れを区別する。
受け入れ検査: 実CLI/HTTPで正常受理から完了、実行中status/cancel、期限/取消/遅延、旧session・新plan/input、切断/再接続、開始応答消失、重複開始、プロトコル不一致、容量/形式異常、保持切れ、v2互換を確認。fake timerの成功だけで実接続完了としない。
