# 接続からの保守的到達可能性（#224）

開始main: b1e80e1d25490374da15602d697ef01361a6cf66。#216/#219の内部境界を前提とし、
editor/src/graphReachability.tsへ既存Graph/Definitionだけを使う純粋な静的解析を追加。
指定Nodeから宣言済み出力/入力の接続を辿り、到達Nodeごとに最短の代表接続列を返す。
各Nodeの入力から全出力へ影響し得ると仮定する保守的may-reachで、分岐の実実行やデータ内容を予測しない。
port/型/重複入力の索引と反復SCCで既存connectionErrorと同じ判定を行い、全512小Graphの差分検査で互換性を確認する。構造不明部分はissuesへ記録し、
connectionsResolvedは接続構造の解決状況だけを表す。riskは常にnot-assessed。

危険度・外部sink・権限metadata・暗黙の情報流を新定義しない。現行Rust NodeにはRunContextの全文入力や直接OSアクセスがある。
非到達の表示で入力機密性を保証できない。非信頼Nodeの隔離や許可の強制は本解析の役割ではない。
Graph実行/認可/保存/Node APIを変更しない。UIからの利用は#231。
